六地气温爬虫 —— Windows 快速使用说明
====================================

【这是什么】
抓取海南、韶关、梅州、茂名、广州、深圳六个城市每天每个小时的气温和体感温度，
导出成两个 Excel 文件。数据来自 Open-Meteo 免费接口，不需要注册、不需要密钥。

【第一次使用（只做一次）】
本机需要 Python 3.11 或更高版本。
在项目文件夹里按住 Shift 右键 →「在此处打开 PowerShell 窗口」，然后执行：

  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -e .

【以后每次使用】
方法一：双击「运行.bat」。
方法二：在项目文件夹打开 PowerShell，执行：

  .\.venv\Scripts\python.exe -m sixcity_temp

【运行结果】
程序会在「输出」文件夹里生成两个文件：
  六地气温(历史+预报).xlsx      每天 24 个小时的气温
  六地体感温度(历史+预报).xlsx  每天 24 个小时的体感温度

【常见问题】
问：窗口里的中文是乱码？
答：正常情况下不会出现。程序的中文提示由 Python 输出，
    「运行.bat」本身只用英文，避免不同系统代码页导致的乱码。

问：提示某个城市抓取失败？
答：电脑需要联网。程序会自动重试 3 次，仍失败就跳过该城市，
    其余城市照常生成，退出码为 1。检查网络后重跑即可。

问：提示文件被占用？
答：生成的 Excel 正被 WPS / Excel 打开时无法写入，关闭文件后重跑。

问：想加快速度？
答：只抓需要的城市，例如 --only-city 广州 --only-city 深圳；
    或缩小历史范围，例如 --history-start 2026-01-01。

【更多参数】
执行 .\.venv\Scripts\python.exe -m sixcity_temp --help 查看完整说明，
项目根目录的 README.md 有更详细的介绍。
